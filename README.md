## 🎮 What is it?

Help a little green ball climb an **infinite staircase floating in space**. Steer left and right to land on each step — the ball auto-bounces upward on its own. Grab golden power boosters for extra height, watch the ball's face change with the action, and see how high you can climb before you fall.

## ✨ Features

| Feature | Description |
|---|---|
| 🌌 **Space background** | Deep blue-purple gradient with twinkling, layered parallax stars |
| 🟢 **Cool green ball** | A bouncy little climber with a face that reacts to what's happening |
| 😊 **Dynamic expressions** | Happy while climbing, sad when falling, energetic ⚡ when boosted |
| ⚡ **Power boosters** | Glowing lightning bolts scattered on random steps — grab one for a run of extra-high jumps |
| ♾️ **Truly endless** | The staircase regenerates forever — climb toward 100,000,000+ if you're good enough |
| 🏆 **Local scoreboard** | Save your name and score to a top-5 leaderboard, stored right in your browser |
| 📱 **Touch + keyboard controls** | Arrow keys, A/D, or tap the left/right side of the screen |

---

## 🕹️ How to Play

1. Open `index.html` in any modern browser (or visit the [live game](#) once deployed).
2. Press **Start Climbing**.
3. Use **← / →** or **A / D** (or tap left/right on mobile) to steer the ball onto each step.
4. Grab **⚡ golden boosters** for a temporary higher jump.
5. Climb as high as you can — falling ends the run!
6. Enter your name to save your score to the local leaderboard.

---

## 🛠️ Tech Stack

- Pure **HTML5**, **CSS3**, and **vanilla JavaScript**
- Renders entirely on an HTML5 `<canvas>` — no frameworks, no build step
- Scores and leaderboard persist via `localStorage`
